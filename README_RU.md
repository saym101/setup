# 🚀 Скрипт первичной настройки Debian/Ubuntu

*[Read in English](README.md)*

Интерактивный Bash-скрипт для автоматизации первичной настройки свежего сервера на Debian или Ubuntu. Упор на безопасность, локализацию и установку базового ПО.

## ✨ Возможности

Меню-интерфейс со следующими пунктами:

* **Локализация системы:** hostname, локаль, часовой пояс.
* **Управление ПО:** установка набора базовых пакетов (git, curl, htop и т.д.) и очистка кэша APT.
* **Синхронизация времени:** полная настройка `chrony` (NTP) с поддержкой своих серверов.
* **Hardened SSH:**
    * Генерация пары RSA-ключей.
    * Конвертация ключей в формат PPK (для PuTTY).
    * Отключение входа по паролю и парольного входа для root.
    * Смена стандартного порта SSH на произвольный или случайный.
* **Безопасность:**
    * **UFW (Uncomplicated Firewall):** интерактивное управление правилами.
    * **Fail2Ban:** защита SSH, веб- и почтовых сервисов от брутфорса с автоматической проверкой конфликтов портов.
* **Управление пользователями:** добавление новых sudo-пользователей с автоматическим деплоем SSH-ключей и логированием данных для входа.
* **Веб-стек:** быстрая интеграция с внешним скриптом установки LAMP/LEMP.

### 🌐 Интеграция с веб-стеком
Скрипт бесшовно интегрируется с моим собственным установщиком LAMP/LEMP:

## 🚀 Быстрый старт

> **Внимание:** скрипт должен быть запущен от **root** или через **sudo**.

1.  **Скачать скрипт:**
    ```bash
    wget https://raw.githubusercontent.com/saym101/setup/main/setup.sh
    ```

2.  **Сделать исполняемым:**
    ```bash
    chmod +x setup.sh
    ```

3.  **Запустить:**
    ```bash
    sudo ./setup.sh
    ```

## 🛠 Детали использования

### Логирование
По умолчанию выключено. Приватные ключи (например, дамп PPK на шаге 6) выводятся на экран, и при включённом логе полная копия сессии — а значит и приватный ключ — осядет на диске. Включать только при отладке самого скрипта:
```bash
sudo bash setup.sh --log
```
Пишет `setup_ГГГГ-ММ-ДД.log` (права 600) в текущую директорию. После отладки — удалить.

### Создание пользователя
При добавлении нового пользователя скрипт создаёт временный файл в директории `./login` с логином, паролем и путями к SSH-ключам. **Обязательно скачайте эти данные и удалите файл с сервера!**

### ⚠ Оставшиеся секреты — прочитать обязательно
Скрипт генерирует незашифрованные (без пассфразы) приватные SSH-ключи и, для новых пользователей, выводит пароль открытым текстом — и то, и другое остаётся на диске:

* **Шаг 6 (SSH-ключи root):** файл `.ppk` выводится на экран для копирования, и скрипт предлагает удалить его после — но **оригинальный** приватный ключ OpenSSH (`~/.ssh/<hostname>-<дата>`) автоматически **не удаляется** и остаётся на сервере.
* **Шаг 9 (добавление пользователя):** файл с данными в `./login/<user>_temp_<дата>.txt` содержит пароль открытым текстом и указывает на незашифрованный приватный ключ в `/home/<user>/.ssh/`. Ни то, ни другое автоматически не удаляется.

Как только скопировали ключ/пароль себе — **удалите копию на сервере**: приватный ключ, который даёт доступ к серверу, бесполезно (и опасно) держать незашифрованным на этом же самом сервере — это просто лишний радиус поражения при компрометации.

### Безопасность прежде всего
Скрипт поощряет хорошие практики:
* Принудительный `prohibit-password` для root по SSH.
* Предложение нестандартных портов SSH.
* Настройка правил Fail2Ban с длительным баном (10ч).
